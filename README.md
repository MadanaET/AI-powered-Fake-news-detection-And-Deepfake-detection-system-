# AI-Powered Fake News Detection and Deepfake Detection System

## 📌 Project Overview
The AI-Powered Fake News Detection and Deepfake Detection System is an intelligent web-based application designed to identify fake news articles and detect deepfake media using Artificial Intelligence, Machine Learning, Natural Language Processing (NLP), and Deep Learning techniques.

This project helps users verify the authenticity of news content and identify manipulated images/videos to reduce misinformation and digital fraud.

- 📰 Fake News Detection using NLP and Machine Learning
- 🎭 Deepfake Image/Video Detection using Deep Learning
- 📊 User-friendly Dashboard
- 🔐 Secure Authentication System

- ⚡ Real-time Prediction Results

## ⚙️ How It Works

### Fake News Detection

1. User enters a news article or text.
2. NLP techniques preprocess the content.
3. Machine Learning model analyzes the text.
4. System predicts whether the news is Real or Fake.

### Deepfake Detection

1. User uploads an image or video.
2. Deep Learning model extracts facial features and frame patterns.
3. AI model detects manipulation artifacts.
4. System displays whether the media is Real or Deepfake.

## ▶️ Installation Steps

### Clone the Repository

```bash
git clone https://github.com/MadanaET/AI-powered-Fake-news-detection-And-Deepfake-detection-system-.git
```

### Navigate to Project Folder

```bash
cd AI-powered-Fake-news-detection-And-Deepfake-detection-system-
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Backend Server

```bash
python app.py
```

### Run Frontend

```bash
npm install
npm start
```
